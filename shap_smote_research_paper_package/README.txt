SHAP-SMOTE Research Paper Package

Contents:
- revised_shap_smote_paper.pdf: compiled 8-page paper
- main.tex: LaTeX source
- IEEEtran.cls: IEEE conference document class
- figures/: figures referenced by main.tex

To rebuild (with a LaTeX installation):
  pdflatex main.tex
  pdflatex main.tex

Note: This package contains the revised paper and its LaTeX source/assets.
It does not include the complete SHAP-SMOTE Python project codebase.
